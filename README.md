# Olanike Olatunji — Portfolio

A sleek, dark-themed portfolio for **Olanike Olatunji**, AI Automation & Software Engineer.

Built with Next.js 16, TypeScript, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Structure

- `src/data/portfolio.ts` — All content (projects, experience, certs, contact info)
- `src/components/` — Section components
- `public/certs/` — Kaggle certificate images

## Customize

Edit `src/data/portfolio.ts` to update projects, experience, skills, and contact details. Add a profile photo by replacing the placeholder in `About.tsx`.
